# بتلة — Batla

ثيم لمتاجر الورد والهدايا على منصة سلة، مبني على محرك Twilight (فرع من الثيم الرسمي Raed، رخصة MIT).

## الهوية
- **هيدر شفاف** يطفو فوق صورة كاملة العرض في الرئيسية: القائمة والسلة وخانة بحث زجاجية في جهة اليمين، وروابط نصية في جهة اليسار.
- **الصفحات الداخلية**: شريط فيه صورة مموّهة، واسم المتجر في المنتصف، والشعار في جهة اليسار.
- **شعار بارز** على الحافة السفلية للصورة الرئيسية.
- **أزرار بإطار مزدوج**، وشبكة منتجات بأسلوب مجلات الموضة، وقسم «قصة المتجر» فوق صورة.
- لون الأزرار والعناوين يأتي من «لون المتجر» في سلة. خلفية الصفحات كريمية ويمكن تغييرها من الإعدادات.

## العناصر الجديدة في الصفحة الرئيسية
| العنصر | المسار | الحقول |
|---|---|---|
| صورة رئيسية بنص | `home.hero` | الصورة، العنوان، السطر الثاني، زر اختياري، الارتفاع، نسبة التعتيم، إظهار الشعار |
| أزرار بإطار مزدوج | `home.pill-links` | من ١ إلى ٦ أزرار، لكل زر نص ورابط |
| مختارات المنتجات | `home.featured-grid` | العنوان، المنتجات (إن تُركت فارغة تظهر أحدث المنتجات)، زر «عرض الكل» |
| قصة المتجر | `home.story` | صورة الخلفية، العنوان، النص، نسبة التعتيم، الشعار بنسخة فاتحة |

## إعدادات الثيم (قسم «بتلة — الهيدر والشفافية»)
- تفعيل الهيدر الشفاف فوق صورة الرئيسية
- شفافية خانة البحث، ووضوح الأيقونات، وتعتيم هيدر الصفحات الداخلية
- صورة هيدر الصفحات الداخلية، والاسم المكتوب فيه، ولون خلفية الصفحات

> عند التثبيت يجب أن يكون أول عنصر في الصفحة الرئيسية «صورة رئيسية بنص»، لأن الهيدر الشفاف يطفو فوقه.

## التطوير
```bash
npm install -g @salla.sa/cli
pnpm install
salla theme preview      # معاينة على متجر تجريبي
pnpm run production      # بناء ملفات public/
```
للنشر: ارفع المجلد إلى مستودع GitHub واربطه في Salla Partners من «الثيمات ← استيراد ثيم»، أو استخدم الأمر `salla theme push`.

## الملفات التي عُدّلت عن Raed
- `src/views/components/header/header.twig`: الهيدر الجديد ودرج القائمة على سطح المكتب
- `src/views/components/home/{hero,pill-links,featured-grid,story}.twig`
- `src/assets/styles/04-components/batla.scss`
- `src/assets/js/partials/batla-drawer.js`، مع سطرين في `app.js`
- `src/views/layouts/master.twig`: خط اسم المتجر اللاتيني، ولون الخلفية، والكلاس `theme-batla`
- `twilight.json`: الاسم، والإعدادات، والعناصر
